## 功能分类

### 核心功能
- **数据库管理**：多数据库支持与自动连接处理
- **模型系统**：Django风格的模型与自动表生成
- **查询API**：支持SQLAlchemy表达式的链式查询
- **类型安全**：完整的类型注解和验证

### 模型定义
- **智能字段参数**：基于字段特性自动推断init、repr、compare参数
- **构造器控制**：通过init参数进行字段级模型构造器参与控制
- **from_dict方法**：实例创建期间智能处理不同字段类型

### 高级功能
- **智能操作**：保存操作的自动CREATE/UPDATE检测
- **批量处理**：大数据集的高性能批量操作
- **信号系统**：数据库操作的全面生命周期钩子
- **字段增强**：字段级性能优化和代码生成控制

### CRUD操作
- **统一实例创建**：ObjectsManager方法使用from_dict确保一致的实例创建行为
- **脏字段跟踪**：自动跟踪字段修改以优化UPDATE操作
- **智能操作检测**：自动确定INSERT与UPDATE操作

### 性能功能
- **连接池**：优化的数据库连接管理
- **内存管理**：迭代器支持和高效分页
- **字段级优化**：延迟加载和活动历史跟踪
- **查询优化**：关系加载和查询分析工具
- **批量操作**：批量数据10-100倍性能提升
